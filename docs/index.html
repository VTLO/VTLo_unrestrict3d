VTLo_unrestrict3d

Offline on-device chat. GPU + MTP, CPU fallback. No internet permission.

⬇ Download APK (arm64, ~90 MB)Android 12+ · debug-signed Source on GitHub

Install

  1. Download the APK, open it, allow “install unknown apps” for your browser.
  2. Open the app, tap IMPORT MODEL, pick your .litertlm file.
  3. Wait for the backend line (e.g. GPU · MTP), then chat.

Reinstalling over an older build signed with another key requires uninstalling first.
